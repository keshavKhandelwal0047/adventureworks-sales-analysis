# AdventureWorks Sales Analysis

## Project Overview
An end-to-end sales analysis project using SQL Server and Microsoft Power BI to explore sales data, prepare analytical datasets, and present business insights through a dashboard.

## Tools & Technologies
- **SQL Server** — Data extraction and querying
- **Microsoft Power BI** — Data visualization and reporting
- **SQL** — Joins, filtering, aggregations, and analytical queries

## Project Structure
- `sql/` — SQL scripts for calendar, customer, product, and internet sales data.
- `power-bi/` — Power BI report (`.pbix`).
- `AdventureWorksDW2025.bak` — Data warehouse database backup.
- `AdventureWorksLT2025.bak` — AdventureWorks LT database backup.

## SQL Analysis
The SQL scripts cover:
- Calendar and date attributes
- Customer information
- Product categories and subcategories
- Internet sales transactions and sales measures

## Power BI Dashboard
Open `power-bi/Sales Report.pbix` in Microsoft Power BI Desktop to explore the report.

Added a screenshot of the dashboard here to provide a quick preview.

## How to Run
1. Restore the relevant database backup in SQL Server Management Studio (SSMS).
2. Execute the SQL scripts in the appropriate database context.
3. Open the Power BI report in Power BI Desktop.
4. Configure the data source and refresh the report if required.
